# Réel vs simulé

Anything simulated carries a visible **Simulé** badge in the UI.

| Part                                                                  | Status                                                                      | Notes                                                                                                                                                                                                                                              |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Wave data (Open-Meteo: ECMWF WAM + NCEP GFS-Wave, ERA5-Ocean history) | **Réel**                                                                    | Raw responses hashed (SHA-256) and the hashes published in each attestation.                                                                                                                                                                       |
| Oracle signatures (BIP340 Schnorr, pre-committed nonce)               | **Réel**                                                                    | Tested against official BIP340 vectors.                                                                                                                                                                                                            |
| Nostr publishing (kinds 88/89/30078/1)                                | **Réel** when `NOSTR_PUBLISH=true`                                          | Docker default signs and stores but does not publish (dry run); the CLI has `--dry-run`.                                                                                                                                                           |
| Lightning wallet                                                      | **Simulé** by default (`WALLET_MODE=fake`), **réel** with `WALLET_MODE=nwc` | FakeWallet makes BOLT11-shaped invoices whose preimages hash to the payment hash.                                                                                                                                                                  |
| Crews                                                                 | **Démo**                                                                    | Équipages de démonstration with team-controlled Lightning addresses. No real fisher is enrolled.                                                                                                                                                   |
| SMS                                                                   | **Simulé** (console) or Africa's Talking **sandbox**                        |                                                                                                                                                                                                                                                    |
| USSD                                                                  | Africa's Talking **sandbox**                                                |                                                                                                                                                                                                                                                    |
| Mobile-money cash-out (Wave / Orange Money)                           | **Simulé**                                                                  | Interface only; no real API calls.                                                                                                                                                                                                                 |
| Replays of past days                                                  | **Rejeu**                                                                   | Separate demo oracle key and `ndox-replay` tag; event times are simulated (D-1 20:00 → D 05:15), never published unless asked.                                                                                                                     |
| Replay wave data                                                      | **Réel** (archived)                                                         | Raw Open-Meteo responses for the past day, committed with URL, fetch time and SHA-256. Open-Meteo serves past days from its archive of model runs, so this is not guaranteed to be byte-identical to the forecast available at 05:00 that morning. |
| 7-day outlook (`/api/forecast`)                                       | **Réel**, not attested                                                      | Same models and rule as the oracle; shown as a forecast, never signed.                                                                                                                                                                             |
| BTC price (FCFA ↔ sats)                                               | **Réel** (mempool.space)                                                    | If unreachable: last known price, then the committed seed price, both shown as stale.                                                                                                                                                              |
| Pool deposits, premiums, sponsor invoices                             | **Simulé** with `WALLET_MODE=fake`, **réel** with `nwc`                     | The _Simuler le paiement_ button exists only with the FakeWallet.                                                                                                                                                                                  |
| Zaps to the pool (NIP-57)                                             | **Réel**, `WALLET_MODE=nwc` + `POOL_LIGHTNING_ADDRESS` only                 | Counted only when the pool's own wallet confirms the payment.                                                                                                                                                                                      |
| Demo crews' premiums (`ndox seed-demo`)                               | **Simulé**                                                                  | Paid from a simulated wallet account, backdated by the waiting period; demo cover is never paid by a real wallet.                                                                                                                                  |
| Payouts                                                               | **Simulé** with the FakeWallet and in replays, **réel** with `nwc`          | Every payout stores its payment hash and preimage; replays pay demo crews from a separate simulated account.                                                                                                                                       |
| In-browser verification (`/verifier/:id`)                             | **Réel**                                                                    | Signature, nonce, rule, raw-data hashes and payment preimages are recomputed in the visitor's browser. Relay lookup is skipped for replays and when the server does not publish (dry run), and says so.                                            |
| Interface languages                                                   | **Réel**: français, English                                                 | Wolof is not shown until a native speaker has reviewed it.                                                                                                                                                                                         |
| SMS step in the replay timeline                                       | **À venir**                                                                 | Shown as not yet available; nothing is sent or simulated.                                                                                                                                                                                          |
